# Synthetic bootstrap feedback — NOT real user data

`feedback.jsonl` holds **800 synthetic feedback records** generated by
`python -m app.feedback.generate_bootstrap --count 800 --seed 13`.

* Every record has `"is_synthetic": true`, `"source": "synthetic_bootstrap"` and a synthetic user id
  (`synthetic-user-001` … `synthetic-user-060`). No real person wrote any of it.
* Places are real records from the organisers' PS-13 dataset and the curated Hampi pack, so the
  profiles attach to places GeoGuide actually stores. The *opinions* are simulated: each place gets
  a latent character from its category and tags, each synthetic traveller a persona, and ratings
  follow persona fit + place quality + noise (some places are polarising; negatives are explicit).
* Purpose: develop and test aggregation, place vibe profiles, user preferences and ranking before
  real feedback exists. Real feedback gradually outweighs it; set `FEEDBACK_INCLUDE_SYNTHETIC=false`
  (and `AUTO_SEED_FEEDBACK=false`) to exclude it entirely. The API and UI label community signals
  that include synthetic records.

Fields: feedback_id, user_id, place_id, place_name, city, category, visit_date, overall_rating,
recommendation, vibes, liked_aspects, disliked_aspects, crowd_level, price_level, ambience_score,
cleanliness_score, service_score, accessibility_score, photo_worthiness, text_feedback,
is_synthetic, source, persona (the simulated persona, for testing only). Sentiment and derived
vibe scores are computed on import, like for real feedback.
